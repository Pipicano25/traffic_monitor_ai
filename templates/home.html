🚗 Sistema inteligente de monitoreo vehicular

Conteo y señalización automática de carros

Esta interfaz permite subir una imagen de una vía, parqueadero o zona de tráfico. El sistema ejecuta el modelo ONNX, cuenta los vehículos detectados y genera una imagen con recuadros sobre cada detección.

1. Cargar Selecciona una imagen.
2. Predecir El modelo ONNX analiza la imagen.
3. Señalar Se dibujan recuadros en los carros.
4. Descargar Descarga imagen, JSON o TXT.
